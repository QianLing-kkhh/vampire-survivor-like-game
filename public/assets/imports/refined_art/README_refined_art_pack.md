# Refined Art Pack

Generated refined prototype assets for `public/assets/art`.

## Character movement

- Existing runtime-compatible per-direction files remain 64x64, 4 horizontal frames.
- Additional full walking sheets are included as `walk_8dir_sheet.png`: 80x80 frames, 4 columns x 8 rows.
- Direction row order: up, up_right, right, down_right, down, down_left, left, up_left.

Copy the `public` folder into the project root to replace `public/assets/art`.
